📊 COVID-19 Data Analysis using SQL

(India & Global Perspective)

🔍 Project Overview

This project focuses on analyzing the global COVID-19 dataset (2020–2021) to understand patterns related to cases, deaths, population impact, and vaccination trends.
The analysis was performed entirely using SQL (SSMS), with an emphasis on time-based trends, country-level comparisons, and meaningful insight communication.

The final insights are presented in a structured PPT, designed for clear stakeholder communication rather than raw dashboards.

🛠 Tools & Technologies

SQL Server (SSMS) – data querying & analysis

SQL – joins, aggregations, window functions, time-based analysis

PowerPoint – insight storytelling & presentation

📁 Repository Contents

→ Final presentation containing insights, trends, and observations

README.md

Note: Raw datasets and SQL scripts are intentionally excluded to keep the repository concise and focused on insight delivery.

📌 Key Analysis Themes

Total cases vs total deaths (country & continent level)

Death percentage trends over time (global & India-specific)

Population vs infection rate analysis

Worst-affected countries and regions

Vaccination rollout trends using window functions
